# Banner & Creative Specs — EFK Battles

> Source: banner-design skill. Reusable creative directions for ads, social, and the site hero. All assets should use the brand tokens in assets/design-tokens.css.

## Approved Art Directions

### 1. "Blaze Dark" (default)
- Black background #0A0A0A with subtle radial green glow (rgba(156,204,101,0.08))
- Blaze green #9CCC65 headline (Russo One), white body (DM Sans)
- Big KES figures with tabular numerals
- Uses: site hero, OG image, Instagram/TikTok cover

### 2. "Scoreboard"
- Black frame, green LED-scoreboard style numbers
- "You 3 : 1 Them" motif; headline uses countdown numbers
- Uses: ad creatives, countdown posts, bracket teasers

### 3. "Payout Proof"
- M-Pesa-style confirmation green check + KES 1,600 amount
- "Winner takes 50%" caption
- Uses: trust/social proof, retargeting, WhatsApp share
- Caution: never forge a fake M-Pesa receipt; use real blurred screenshots

## Copy Hierarchy (per banner)
1. Hook (≤6 words): "KES 100 in. KES 1,600 out."
2. Support: "32 spots. First come, first served."
3. Hard CTA: "Join Now" / "Link in bio" / "Register"
4. Legal/small: "Skill-based tournament • 18+ (13+ w/ consent) • Partner: Blaze by Safaricom"

## Brand Guards
- Never use emoji as the hero element; only SVG/Lucide icons
- Never place Blaze/M-Pesa logo recolored, rotated, or on busy backgrounds
- Always include the Safaricom disclaimer reference on persistent assets (footer link)
- Text contrast ≥ 4.5:1 on all body copy
- Respect reduced motion (no flashing if animated)
